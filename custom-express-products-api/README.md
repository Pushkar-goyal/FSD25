# Custom Express Products API

A simple Express.js REST API with 100 generated products.

## Install

```bash
npm install
```

## Run

```bash
npm start
```

## Endpoints

- GET /api/products
- GET /api/products/:id
- POST /api/products
- PUT /api/products/:id
- PATCH /api/products/:id
- DELETE /api/products/:id
- GET /api/products/categories
- GET /api/products/stats
